# WSET L3 Study

Flashcards and a term-first quiz for WSET Level 3. Original study copy, not a textbook dump.

**Live:** https://wset-l3-study.pages.dev

## Run locally

Open `index.html` in a browser. Decks are embedded, so no server is required.

## Deploy

```
npx wrangler pages deploy . --project-name wset-l3-study
```

## Contents

- `index.html` — player
- `decks.json` — five decks (SAT, vine/climate, vineyard, winemaking, law)
- `schema.md` — card format
- `wrangler.jsonc` — Pages assets config
